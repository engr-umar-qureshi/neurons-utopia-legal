Privacy Policy

Last updated: 27 September 2026

Neurons Utopia Uploader ("the Tool") is a personal content-management tool operated by its creator for publishing the creator's own videos to the creator's own TikTok account. This policy explains what data the Tool handles.

1. Data the Tool accesses

  • TikTok account basics (username, avatar) via the user.info.basic scope — used only to confirm which account is connected before publishing.
  • Video files you choose to publish via the video.publish scope — transmitted to TikTok solely to create the post you explicitly approved.

2. What we do NOT do

  • No data is sold, shared, or disclosed to third parties.
  • No analytics, tracking, advertising, or profiling.
  • No data from any other person is collected — the Tool is used by a single operator for a single account.

3. Data storage

OAuth tokens are stored locally on the operator's own computer and never transmitted anywhere except to TikTok's official API endpoints. You may revoke access at any time via TikTok Settings > Security > Manage app permissions, which immediately stops the Tool from acting on your account.

4. Data deletion

To delete everything the Tool holds: revoke the app's access in TikTok settings (above) and delete the local token file. Contact engr.umar.qureshi@gmail.com for any privacy questions.
